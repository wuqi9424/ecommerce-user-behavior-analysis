# 电商用户行为分析：项目分析总结

## 1. 项目目标

我基于公开电商行为数据，使用 SQL 和 Python 分析用户活跃、转化、留存与重复购买，并结合 RF 与行为特征识别不同用户群体。项目重点是统一指标口径、核对分析结果，再将行为差异转化为值得验证的运营方向。

这是公开数据作品集，不是企业内部项目，也没有商业上线或已验证的营销效果。

## 2. 数据与分析范围

数据来自 [Alibaba Tianchi / Taobao UserBehavior](https://tianchi.aliyun.com/dataset/649)。本项目分析 **2017-11-25 至 2017-12-03** 的九天行为，时区为 **Asia/Shanghai**；清洗后共 **100,095,182 条事件、987,991 位用户**。

行为包括浏览（pv）、收藏（fav）、加购（cart）和购买（buy）。buy 是事件，不是订单；窗口内首次观测活跃日不是注册日。原始数据准备方式见 [数据说明](../data/README.md)。

## 3. 分析方法

我先检查字段、时间范围、行为类型和重复记录，再依次完成平台活跃、转化、留存、购买日期频次与用户分层，最后用 Python 核对 SQL 结果并绘制中文画像。

主要方法与口径：

- **清洗与质量检查：**限定日期和四类行为，对完全相同的日志去重；该处理是日志去重假设，不将一般重复行为当成异常。
- **转化分析：**无序集合漏斗只表示行为覆盖；严格路径另要求同用户、同商品、时间递增，不假定所有用户经历固定的浏览—收藏—加购—购买流程。
- **活跃留存：**基于首次观测活跃 cohort，不是新注册 cohort；没有完整后续窗口的单元格为 NULL，不能解释为流失。
- **重复购买：**至少两个不同日期发生 buy 才算跨日重复购买；相同日期多条 buy 不构成跨日重复购买。
- **RF + 行为特征：**Recency 固定锚定 **2017-12-03**；Frequency 优先采用不同购买日期数，再结合活跃、浏览、收藏与加购。没有交易金额，因此不人为构造 Monetary，也不称为标准 RFM。
- **规则分层：**阈值来自实际分位点，按优先级首次命中，最终群体互斥。整数并列可能使达到分位阈值的人数不等于固定比例；标签不代表长期生命周期。

方法与结果入口：[分层 SQL](../sql/06_user_segmentation.sql)、[画像 Notebook](../notebooks/05_user_segmentation_visualization.ipynb)。

## 4. 核心发现

| 发现 | 数据证据 | 解释边界 |
|---|---|---|
| 窗口内重复购买 | 672,404 位购买用户中，370,274 人跨日购买，Observed Repeat Purchase User Rate 为 55.07% | 不是订单复购率或长期复购率 |
| 高活跃未购买 | 105,478 人，平均活跃 8.48 天、浏览 118.25 次，90.01% 有加购或收藏 | 值得调查兴趣到购买的障碍，不能保证未来购买 |
| 加购未购买 | 129,320 人，占未购买用户 40.98%，平均加购 4.85 次 | 有意向信号，但不能确认未购买的具体原因 |
| 购买沉寂仍活跃 | 154,066 人，97.67% 在最后一天仍活跃 | 不能仅凭购买 Recency 判为流失 |
| 高参与购买 | 63,055 人，平均购买日期 4.07 天、购买品类 5.68 个 | 行为参与强，不代表金额贡献最高 |

## 5. 重点用户群体

### 购买沉寂观察用户

购买 Recency 大于购买人群 Q75（**4 天**）的用户被归入此群体，平均距最后购买 **6.28 天**。我进一步检查平台活跃，发现 **97.67%** 在窗口最后一天仍有行为，平均浏览 **96.84 次**、加购 **5.81 次**。

“未再次购买”和“离开平台”是不同状态。仍在比较商品或等待购买时机是可能的解释，但当前数据不能证明原因。更合适的研究方向是结合最近浏览兴趣与品类购买节奏，区分购买沉寂和平台不活跃。

图表：[购买沉寂与平台活跃](figures/08_purchase_cooling_activity.png)。

### 高活跃未购买与加购未购买用户

前者体现持续参与，后者有直接加购信号。最终分层中，高活跃未购买先于加购与收藏规则，因此加购未购买群体不等于全部有加购但没有 buy 的用户。这两类人群值得优先调查转化障碍，但不是已确认的未来购买者。

### 高参与购买与其他已购买用户

高活跃高频购买用户在当前窗口内持续活跃，并在多个日期、多个品类发生购买，可以作为权益与推荐测试的关注对象，不能据此判断收入贡献。

“其他已购买”共 **108,051 人**，购买 Recency 为 **3–4 天**、购买日期为 **1–2 天**，平均活跃 **7.36 天**。他们没有命中近期、高频或沉寂规则，是规则中的中间状态，不是异常用户。这个结构可用于后续解释优化，本次不改变分层。

## 6. 业务启示

我将建议限定为待验证方向，而非已经证实有效的策略：

| 人群 | 可考虑的方向 |
|---|---|
| 高活跃未购买 | 先调查浏览到购买的障碍，再测试商品推荐或优惠 |
| 加购未购买 | 测试购物车召回；价格变化与库存提醒需要补充实时商品数据 |
| 购买沉寂但仍活跃 | 结合近期兴趣测试再购买推荐，区别于平台不活跃者 |
| 高活跃高频购买 | 测试会员权益、个性化推荐与新品触达 |
| 相对低活跃仅浏览 | 低成本兴趣探索，控制触达频率与成本 |

如开展验证，应统一后续观察窗口，尽可能随机分组，同时评估增量购买用户、成本和负面反馈。当前分析没有证明任何措施的因果效果。

## 7. 分析限制

- 只有九天，窗口前历史与窗口后行为不可见，存在左右截尾。晚出现用户的观察机会更少；首次观测日不是注册日。
- 没有 order_id、价格与交易金额。buy 不能作为真实订单数，也不能计算消费金额、GMV、Monetary 或 CLV。
- 窗口内重复购买不能解释为长期复购率，购买沉寂不能解释为长期流失；无法判断真实长期留存。
- 公开样本不能代表平台全量人群。分位标签只表示当前样本中的相对状态，画像差异部分来自规则本身，不代表预测能力。
- 无序集合不证明有序购买路径；缺少 Session 与更长观察期，路径归因与购买周期解释存在边界。
- 没有营销触达或实验结果，运营方向仍需验证。项目未实现机器学习模型或商业部署。

## 8. 后续可扩展方向

| 补充数据 | 可研究方向 |
|---|---|
| 订单 ID、金额、退款与商品价格 | 真实订单频次、净消费金额、标准 RFM；更长历史支持 CLV |
| 注册日期与更长观察期 | 真正新用户 cohort retention、长期留存与生命周期 |
| 曝光、Session 与商品信息 | 有归因窗口的转化分析，随后评估 conversion modeling |
| 营销触达、优惠券使用、成本与实验分组 | 优惠响应、campaign uplift / A/B testing |
| 更长历史与可验证的流失定义 | churn modeling，使用时间划分验证以防止信息泄漏 |

这些方向尚未实现。我会优先补齐数据与业务定义，再判断是否需要建模；已有“其他已购买”结构和购买沉寂群体的最近活跃特征，也可作为下一阶段的研究起点。
